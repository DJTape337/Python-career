## 4. Практический проект UniWork

**Идея:** получить расписание университета из API, преобразовать его в
занятые интервалы, вычислить свободное время по дням недели и в
дальнейшем сопоставить его с вакансиями, график которых подходит
пользователю.

Известный источник данных: - API расписания Донского государственного
технического университета. - Использовавшийся endpoint:
`https://edu.donstu.ru/api/Rasp?idGroup=73007&sdate=2026-10-20` - Метод:
GET. - В JSON использовалась структура `data.rasp`. - Изучавшиеся поля:
`день_недели`, `датаНачала`, `датаОкончания`, `дисциплина`.

Уже выполнялось: - получение ответа API через `httpx`; - сохранение JSON
в файл; - извлечение списка занятий; - получение уникальных дней
недели; - преобразование времени начала и окончания через
`datetime.fromisoformat()`; - форматирование времени для вывода.

Следующие возможные задачи проекта определяются текущей учебной темой.
Не считать весь функционал проекта готовым.
